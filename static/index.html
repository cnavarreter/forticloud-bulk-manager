1Connect to FortiCloud

Use an IAM API user (FortiCloud → Services → IAM → Users → Add New → API User) whose permission profile includes Asset Management. Credentials stay in this app's memory only and are never written to disk.

    2Choose an operation

    Each operation has its own template. Download it, fill one row per product, then load it below.

    Columns for this operation
    ColumnDescriptionExample

    Column names are matched loosely (e.g. "Serial Number", "SN" and "serial" all work). Unknown columns are ignored.

    3Load and check your data

    CSV or Excel (.xlsx, first sheet, header row first). Rows are validated locally before anything is sent.

    Drop a .csv or .xlsx file here or click to choose
    …or paste rows (copy from Excel, including the header row)

    4Review and run

    Use Dry run to see the exact API requests without sending anything. Run sends them to FortiCloud.

    Run settings (rate limits & batching)
    Registration is capped at 10 (FortiCloud limit).
    FortiCloud allows 100/min.
    FortiCloud allows 1000/hour.
    FortiCloud allows ~10 errors/hour per API user.
